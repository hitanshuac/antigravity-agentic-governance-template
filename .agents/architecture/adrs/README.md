# Architecture Decision Records (ADRs)

This directory contains the Architecture Decision Records for the project. 
Because this is a governance template, it ships with this directory empty to provide a clean slate for your new repository.

When making architectural decisions that resolve ambiguity (e.g., choosing a database, picking an authentication provider, deciding between two design patterns), **you MUST write an ADR here before writing code.**

Use the standard format (Status, Date, Context, Options Evaluated, Decision, Rationale, Consequences).
